# TrendRadar 专项流程（指针）

命中 TrendRadar 输入时 **只读本文件 + `references/raw/trendradar/README.md`**，不要走通用 wiki 流程。

## 命中特征

- 文本含「TrendRadar」/「热点词汇统计」/「热点分析报告」/「当日汇总」
- 多源条目：`[GitHub] …`、`[V2EX] …`、`[掘金] …`、`[Hacker News] …`
- 用户明说「TrendRadar 当日 / 每日资讯 / 投喂热点」

## 必读

`references/raw/trendradar/README.md` — Level 0/1/2、watchlist、`_cache/`、Reviewer、抓图策略的完整定义。

## 要点（勿与通用流程混用）

| 项 | 约定 |
|----|------|
| Raw | `references/raw/trendradar/YYYY-MM-DD.md` + URL 表 |
| 月度页 | `wiki/topics/market-trendradar-YYYY-MM.md` 倒序 ≤5 行 |
| Watchlist | `wiki/topics/market-trendradar-watchlist.md` |
| 抓图 | **选择性**（架构/数据/关键截图；装饰/头像/二维码跳过） |
| 口令 | Level 0/1/2、深挖 #N、升 #N、跳过抓图、reviewer 档位 |

判断为 TrendRadar 后：**不要**落到顶层 `references/raw/` 或单独 deep-dive topic 污染月度页（除非用户明确要求 Level 2 深挖并开独立 topic）。
